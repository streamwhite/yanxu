# 雁序

用于 Bilibili、抖音和视频号(微信)创作中心的自动上传并填写内容：旨在提高投稿效率和准确度.

## 使用

1. 登录各个平台(视频号需要至少每天重新登录一次).从[这里](https://dl.piaosiyuan.cn/?path=%E9%9B%81%E5%BA%8F) 在 `chrome://extensions`（Edge：`edge://extensions`；Opera：`opera://extensions`）开启开发者模式，选择“加载已解压的扩展程序”，加载解压后的扩展文件夹（该文件夹中应直接包含 `manifest.json`；）。
2. 点击浏览器工具栏中的雁序图标，打开弹窗。
3. 首次使用时，在弹窗点击“选择任务与素材”，进入选项页面。
4. 点击“任务文件”，选择任务 `.json` 或 `.xlsx` 文件。
5. 点击“素材文件夹”，选择视频和图片所在目录。
6. 在设置页选择任务文件和素材文件夹后，打开弹窗点击“开始”。扩展会读取任务、视频和图片并填充发布字段直到出现相关提示；检查各平台页面后手动提交。

发布包内的 `examples/` 文件夹提供 JSON 和 XLSX 批量任务示例，覆盖全部字段和常见情况。JSON 使用中文字段名，且可省略任务版本和素材路径；XLSX 也使用中文表头。

浏览器重启后如果访问权限失效，打开弹窗会自动跳转到设置页，点击“恢复访问”即可。

这个工具和各个平台包含上传限制.这个工具限制为30个每天,足够正常情况使用了.
上传期间最好不要动电脑,因为不同平台固有限制.

### 注意

任务文件及素材文件夹必须位于当前操作系统用户有权访问的文件夹中。浏览器出于安全限制，只能读取用户的文件夹,可将文件放在当前用户的文档目录中，例如：

- Windows：`C:\Users\Alice\Documents\Yanxu\job.json` 和 `C:\Users\Alice\Documents\Yanxu\素材`
- macOS：`/Users/alice/Documents/Yanxu/job.json` 和 `/Users/alice/Documents/Yanxu/素材`
- Linux：`/home/alice/Documents/Yanxu/job.json` 和 `/home/alice/Documents/Yanxu/素材`

任务文件支持 JSON 和 XLSX；JSON 使用“任务列表”“名称”“描述”等中文字段，XLSX 只使用第一个工作表。示例文件已覆盖全部字段和常见情况，可直接复制修改：

| 字段（XLSX 表头） | JSON 字段      | 说明                                    |
| ----------------- | -------------- | --------------------------------------- |
| 名称              | `名称`         | 必填；同时作为视频和图片的文件名        |
| 描述              | `描述`         | 发布描述                                |
| 标签              | `标签`         | JSON 用数组；XLSX 用 `\|` 分隔          |
| 来源              | `来源`         | `原创` / `转载`                         |
| B站分区           | `B站分区`      | 仅 Bilibili 使用                        |
| 创作声明          | `创作声明`     | 如 `含AI生成内容`                       |
| 创作声明授权      | `创作声明授权` | 如 `内容为自制：未经作者允许，禁止转载` |
| 视频号标注        | `视频号标注`   | 如 `含AI生成内容` / `内容为转载`        |

发布平台由弹窗“平台范围”选择。封面不需要在任务中声明：素材文件夹存在同名图片时会自动填充。示例覆盖填写全部字段、原创/转载，以及只填写“名称”的最小任务。

视频和图片直接放在所选素材文件夹中，不要放入子文件夹。视频及封面图片的文件名（不含扩展名）必须与任务中的“名称”（`name`）完全一致：

- 视频：`{name}.mp4`
- 封面：`{name}.png` / `{name}.jpg` / `{name}.jpeg`
- 横向封面：`{name}-4x3.png` 等

上传之后会停留在封面位置,确认封面后可以提交.

`pnpm package` 输出到 `release/`，两个商店使用同一份扩展包。
